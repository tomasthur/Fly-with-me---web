# Airline Manager - Web

Profesionálny web pre mobilnú hru Airline Manager, kde si hráči môžu vytvoriť vlastnú aerolinku, kupovať lietadlá, najímať pilotov a stewardov, vytvárať lety a riadiť svoju leteckú spoločnosť.

## 🚀 Funkcie

- **Responzívny dizajn** - Optimalizované pre všetky zariadenia
- **Moderný UI/UX** - Použitie špecifikovaných farieb hry
- **Interaktívne komponenty** - Animácie a hover efekty
- **SEO optimalizované** - Meta tagy a štruktúrované dáta
- **Rýchle načítanie** - Next.js optimalizácie

## 🎨 Dizajn

Web používa farby z hry:
- **Primárna tmavá**: `#0c0942`
- **Primárna stredná**: `#10356c`
- **Primárna svetlá**: `#c4dafc`
- **Biela**: `#fff`
- **Červená**: `#ff8181`
- **Žltá**: `#ffdb10`

## 🛠️ Technológie

- **Next.js 14** - React framework
- **TypeScript** - Type safety
- **Tailwind CSS** - Utility-first CSS
- **Lucide React** - Ikony
- **App Router** - Nový Next.js routing

## 📦 Inštalácia

1. Nainštaluj závislosti:
```bash
npm install
```

2. Spusti vývojový server:
```bash
npm run dev
```

3. Otvor [http://localhost:3000](http://localhost:3000) v prehliadači

## 🏗️ Štruktúra projektu

```
src/
├── app/
│   ├── globals.css      # Globálne štýly
│   ├── layout.tsx       # Hlavný layout
│   └── page.tsx         # Domovská stránka
├── components/
│   ├── Navigation.tsx   # Navigačný panel
│   ├── Footer.tsx       # Footer
│   ├── Hero.tsx         # Hero sekcia
│   ├── Features.tsx     # Funkcie hry
│   ├── Screenshots.tsx  # Screenshoty
│   └── Download.tsx     # Stiahnutie hry
└── lib/                 # Utility funkcie
```

## 📱 Sekcie webu

1. **Hero** - Hlavný banner s CTA tlačidlami
2. **Funkcie** - Prehľad funkcií hry
3. **Screenshoty** - Galéria obrázkov z hry
4. **Stiahnutie** - Download sekcia s QR kódom

## 🚀 Deployment

```bash
npm run build
npm start
```

## 📝 Poznámky

- Screenshoty z hry je potrebné nahradiť skutočnými obrázkami
- Logo hry je potrebné pridať do navigácie
- QR kód je potrebné vygenerovať s odkazom na stiahnutie
- Pridať skutočné odkazy na App Store a Google Play
